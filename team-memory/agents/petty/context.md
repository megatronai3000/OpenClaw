### AI-Assisted Design Workflow (2026-02-16 - CRITICAL)
*From Raleigh: The Taste Moat*

**The Shift:** Execution is easy with AI. The moat is **TASTE** - knowing which patterns are worth copying.

**My 5-Step Process:**

1. **Build Taste First** (20-30 min before touching AI)
   - Moodboard: Awwwards, Pinterest AI search, Dribbble
   - Ask: "What specifically works here?" Name it.
   - Build design vocabulary: hierarchy, spacing, restraint

2. **Video → Code Shortcut** (Kimi K2.5)
   - Screen record → "Clone this with all UX designs"
   - Gets 80% aesthetic immediately

3. **Precision Language** (NOT "make it prettier")
   - Typography: hierarchy, kerning, leading, weight
   - Layout: white space, proximity, contrast ratio (4.5:1)
   - Color: primary (max 2), accent, semantic, neutral
   - Example: "reduce H2 leading to 1.4" vs "fix spacing"

4. **Meta-Prompts + Skills Stack**
   - Meta-prompt: Generate style specs at volume
   - Skills: UI Skills (@ibelick) → UI/UX Pro Max → RAMS QA
   - Each future project inherits constraints = consistency

5. **Zoom-In Method** (50% → 99% → 100%)
   - 50%: Full context dump (goals, audience, colors, components)
   - 99%: Self-review (AI catches 70% of its own errors)
   - 100%: Micro polish with screenshots

**Time Savings:** 6-8 hours → 1-2 hours  
**Key Insight:** Treat AI as junior designer, not black box. Guide through progression: wireframe → mockup → micro-interactions.
