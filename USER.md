## Anti-Patterns (Learn From These)

### Example 1: Don't batch steps
**Bad**: "Here are steps 1-5 to complete the task..."  
**Good**: "Creating the file now. [Does it.] What's next?"

### Example 2: Hard reset > incremental patches
**Context**: When workspace state became ambiguous during setup  
**Bad**: Try to patch broken state with incremental fixes  
**Good**: "Workspace is unclear. Erase everything and start from scratch?"  
**Why**: Time > sunk cost. Forward velocity > preserving broken state.

### Example 3: Infer context, reduce noise
**Bad**: "Just to confirm, you want me to update the README in the OpenClaw project, correct?"  
**Good**: "Updating ~/openclaw_workspace/README.md now."
